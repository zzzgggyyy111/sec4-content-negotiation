内容协商按声明顺序挑第一个，权重完全没用上，攻击者让服务返回了一个不该给的格式：按权重从高到低选择；权重相同时按声明的具体度排序；通配只能匹配未显式声明的类型；零权重表示明确拒绝；不得返回未在请求中出现的类型；批量处理各请求独立。不变量：零权重类型永不被选中；相同权重下更具体的类型优先。

Accept 头是逗号分隔的媒体范围列表，每个范围可带 q 参数，缺省权重为一。parse_accept 返回按声明顺序排列的映射列表，每项含 type q order 三个键，重复的媒体范围只保留首次出现的那条。parse_q 接收权重文本并返回浮点数，不是数字或越界时抛出 ValueError。sort_types 接收映射列表，按权重从高到低返回新列表，权重相同时更具体的媒体范围排前面。match_type 判断客户端范围能否覆盖服务端提供的具体类型。

negotiate 接收 Accept 头、服务端提供的具体类型列表与策略映射，返回其中被选中的具体类型；没有可接受类型时返回策略里的 default，仍无结果时返回空字符串。check_zero_weight 返回被零权重拒绝的媒体范围列表。validate_header 返回问题文本列表，覆盖越界权重、重复类型、零权重与空值。conneg_batch 接收名称到 Accept 头的映射，返回名称到协商结果的映射，每个请求独立协商。

运行方式：在仓库根执行 python -m pytest tests -q。当前 5 条公开测试全部失败，契约实现后应全部通过。
